# AIP-0032: Revised AIFP-1 Reference Action Pricing

- **Status:** Accepted
- **Category:** Economics
- **Created:** 2026-08-06
- **Applies to:** AIFP-1

## Summary

This proposal updates the AIFP-1 reference starting prices for agent actions.

| Pricing tier | Reference starting price |
|---|---:|
| `standard` | `$0.0005` per action |
| `complex` | `$0.002` per action |
| `premium` | `$0.005` per action |

These values replace the previous reference prices of `$0.00001`, `$0.00006`, and `$0.00010` wherever those values appear as current protocol pricing.

## Rationale

The previous reference prices made high-volume pay-as-you-go access materially cheaper than authenticated annual plans. The revised prices preserve micropayment economics while creating a rational commercial boundary between occasional metered use and subscription-based access.

At the revised prices:

- 16,000 Standard actions cost `$8.00` per month or `$96.00` per year on pay-as-you-go.
- The weighted reference mix of 85% Standard, 10% Complex, and 5% Premium equals `$0.000875` per action.
- 25,000 actions at the weighted reference mix cost `$21.875` per month or `$262.50` per year.

## Normative rule

Merchants MAY set higher route-, product-, buyer-, workload-, or rights-specific prices. These values are protocol reference starting prices and do not cap merchant pricing.

The AiFinPay protocol fee remains `1%` of every successful transaction. Merchant settlement remains `99%` before external network, processor, gas, foreign-exchange, payout, or settlement costs.

## Compatibility

No message schema or wire-format change is required. Implementations that hard-code the previous prices MUST update their defaults. Explicit merchant-configured prices remain valid.

## Required implementation updates

The following surfaces MUST use the revised defaults:

- protocol documentation and examples;
- merchant SDK defaults;
- agent SDK examples;
- OpenAPI and JSON Schema examples;
- Postman collections;
- MCP and dashboard pricing presets;
- tests, fixtures, and calculators.
