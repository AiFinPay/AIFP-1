## Abstract

Adds a dedicated error for budget-policy breaches at `POST /v1/pay`.

## Motivation

Provide clear feedback when agent payments exceed configured budget policies.

## Specification

### Error Code

`AIFP-403-BUDGET-EXCEEDED`

### HTTP Status

`403 Forbidden`

### Response Body

```json
{
  "error": {
    "code": "AIFP-403-BUDGET-EXCEEDED",
    "message": "Payment exceeds budget policy",
    "details": {
      "policy_id": "pol_*",
      "cap_type": "daily|monthly|per_request",
      "current": "<current_amount>",
      "limit": "<configured_limit>"
    }
  }
}
```

### Trigger Conditions

- Per-request cap exceeded
- Daily cap exceeded
- Monthly cap exceeded
- Per-merchant allowance exceeded

## Backward Compatibility

MINOR — new error code under existing `403` semantics.

## Security Considerations

Budget enforcement prevents runaway agent spending.
