## Abstract

Adds a dedicated error for budget-policy breaches at `POST /v1/pay`.

## Motivation

Provide clear feedback when agent payments exceed configured budget policies.

## Specification

### Error Code

`AIFP-403-BUDGET-EXCEEDED`

### HTTP Status

`403 Forbidden`

### Response Body

```json
{
  "error": {
    "code": "AIFP-403-BUDGET-EXCEEDED",
    "message": "Payment exceeds budget policy",
    "details": {
      "policy_id": "pol_*",
      "cap_type": "daily|monthly|per_request",
      "current": "<current_amount>",
      "limit": "<configured_limit>"
    }
  }
}
```

### Trigger Conditions

- Per-request cap exceeded
- Daily cap exceeded
- Monthly cap exceeded
- Per-merchant allowance exceeded

## Backward Compatibility

MINOR — new error code under existing `403` semantics.

## Security Considerations

Budget enforcement prevents runaway agent spending.

## Status note (2026-08-07)

Downgraded from **Final**: the error code is not what the server emits. A
budget-policy refusal returns `{"error":"agent_policy","reason":…}`
(`backend/routes/gateway.js:216`), not `AIFP-403-BUDGET-EXCEEDED`, and the
`details` object specified here has no counterpart.

Either the server adopts this shape or the AIP records the shape the server
has. Until one of those happens, an integrator matching on the documented code
matches nothing.
