## Abstract

Introduces `pp_*` Agent Passports with Ed25519 identity, reputation ∈ [0,1000] (start 500), risk ∈ [0,100], and trust levels (untrusted/basic/verified/enterprise).

## Motivation

Enable portable agent identity across merchants with reputation-based trust decisions.

## Specification

### Agent Passport

- Format: Ed25519-signed credential (`pp_*`)
- Binds: agent ID (`agt_*`), wallets, budget policies, reputation
- Optional for anonymous payment, REQUIRED for identity-bound features

### Reputation System

- Range: [0, 1000]
- Initial value: 500
- Risk score: [0, 100]

### Trust Levels

| Level | Description |
|---|---|
| `untrusted` | New or flagged agents |
| `basic` | Default after initial activity |
| `verified` | Identity-verified agents |
| `enterprise` | High-volume, KYC-completed agents |

### Endpoints

- `POST /v1/passports` — Issue an Agent Passport
- `GET /v1/passports/{id}` — Retrieve Passport (reputation, risk, trust)

### Features Requiring Passport

- Delegated spending
- Budget policies across merchants
- Reputation-based discounts
- Multi-wallet routing

## Backward Compatibility

MINOR — additive endpoints and optional challenge fields.

## Security Considerations

- Ed25519 signatures prevent forgery
- Key rotation supported
- Delegation chains verifiable
