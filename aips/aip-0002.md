## Abstract

Ratifies AIFP-1 as the normative protocol specification: HTTP-402 challenge, quote/pay/receipt loop, Ed25519 stateless receipts (TTL 600s), agent action pricing tiers, a 1% fee added on top of the merchant amount, idempotency (24h), and error registry.

## Motivation

Establish the baseline payment protocol for AI agent microtransactions.

## Specification

### Payment Flow

1. Agent requests resource
2. Merchant returns `402 Payment Required` with challenge
3. Agent requests quote via `POST /v1/quote`
4. Agent pays via `POST /v1/pay`
5. Agent receives Ed25519-signed receipt
6. Agent retries request with `Payment-Receipt` header
7. Merchant verifies signature locally and grants access

### Pricing Tiers

| Tier | Minimum Price |
|---|---|
| `standard` | $0.00001 |
| `complex` | $0.00006 |
| `premium` | $0.00010 |

### Fee Structure

- Protocol fee: 1% (0.01)
- Merchant settlement: the configured merchant amount in full; the 1% protocol fee is added on top

### Receipt Properties

- Signature: Ed25519
- Default TTL: 600 seconds
- Claims: audience, resource, amount, nonce, expiry

### Idempotency

- Dedupe window: 24 hours
- Key: `Idempotency-Key` header

### Supported Networks

12 chains with stablecoin support (USDC/USDT/PYUSD).

## Backward Compatibility

Baseline; nothing to break.

## Security Considerations

- Receipt forgery prevention via Ed25519
- Replay protection via nonce + expiry
- Stateless verification at merchant
