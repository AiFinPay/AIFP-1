## Abstract

Ratifies AIFP-1 as the normative protocol specification: HTTP-402 challenge, quote/pay/receipt loop, Ed25519 stateless receipts (TTL 600s), agent action pricing tiers, 1% protocol fee, merchant settlement of 99%, idempotency (24h), and error registry.

## Motivation

Establish the baseline payment protocol for AI agent microtransactions.

## Specification

### Payment Flow

1. Agent requests resource
2. Merchant returns `402 Payment Required` with challenge
3. Agent requests quote via `POST /v1/quote`
4. Agent pays via `POST /v1/pay`
5. Agent receives Ed25519-signed receipt
6. Agent retries request with `Payment-Receipt` header
7. Merchant verifies signature locally and grants access

### Pricing Tiers

| Tier | Minimum Price |
|---|---|
| `standard` | $0.00001 |
| `complex` | $0.00006 |
| `premium` | $0.00010 |

### Fee Structure

- Protocol fee: 1% (0.01)
- Merchant settlement: 99% (0.99, before network/settlement costs)

### Receipt Properties

- Signature: Ed25519
- Default TTL: 600 seconds
- Claims: audience, resource, amount, nonce, expiry

### Idempotency

- Dedupe window: 24 hours
- Key: `Idempotency-Key` header

### Supported Networks

12 chains with stablecoin support (USDC/USDT/PYUSD).

## Backward Compatibility

Baseline; nothing to break.

## Security Considerations

- Receipt forgery prevention via Ed25519
- Replay protection via nonce + expiry
- Stateless verification at merchant

## Status note (2026-08-07)

Downgraded from **Final** because the normative numbers in this document do not
match the implementation, and `Final` reads as authoritative to anyone
integrating from the outside.

| This AIP says | The code does |
|---|---|
| tiers `$0.00001 / $0.00006 / $0.00010` | `$0.0005 / $0.002 / $0.005` — fifty times higher (`backend/aifp/pricing.js`, CEO decision 2026-08-07, adopting this repo's own reference prices from `docs/economics.md`) |
| header `Payment-Receipt` | `AIFP-Receipt` (`backend/routes/gateway.js:71`) |
| receipt TTL 600s | 600s single-use, **30 days** for a prepaid batch (`backend/aifp/receipts.js`) |
| merchant settles 99% | 98.99 / 1 / 0.01 fee-inclusive today; fee-on-top with merchant at 100% is the agreed direction |
| "12 chains with stablecoin support" | production settlement runs on Polygon only |

Also missing rather than wrong: receipt **scope** (`exact` / `prefix` /
`merchant`), the prepaid-batch model and its floor, and the fact that the
native path has no on-chain minimum. All three shipped and none is specified
here.

Rewrite from the implementation, then return to Final.
